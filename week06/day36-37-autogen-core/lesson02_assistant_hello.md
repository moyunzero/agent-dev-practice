## 1. 用生活类比先建立画面

想象你雇了一个 **只会文字聊天的助手**（今天就是 `AssistantAgent`）：

1. 你给它一句话任务：「用一句话介绍你自己」  
2. 助手去问「大脑」（本地的 **Ollama 大模型**）  
3. 大脑回一句话  
4. 助手把这句话交给你  

**AutoGen AgentChat** = 微软做的一套「雇助手、让助手协作」的 Python 工具箱。  
今天只雇 **一个** 助手；下一课再学「两个助手轮流说话」。

```text
你（任务） → AssistantAgent（助手） → Ollama（脑子） → 一句话回答 → 打印在终端
```

## 2. 零基础名词（本课只会用到这些）

### Agent（智能体 / 助手）

| 层 | 说明 |
|----|------|
| **是什么** | 程序里一个「有角色设定、会调用模型说话」的对象 |
| **在本课干什么** | `AssistantAgent` 就是那个助手 |
| **怎么区分** | 不是真人；也不是「整个 ChatGPT 网站」。就是你代码里的一个变量 |

### 大模型 / LLM

| 层 | 说明 |
|----|------|
| **是什么** | 根据输入文字生成下一段文字的模型（像会续写的引擎） |
| **在本课干什么** | 真正「想出那句自我介绍」的是它 |
| **怎么区分** | Agent = 工牌+流程；模型 = 脑子。Agent 通过「模型客户端」去喊脑子 |

### Ollama

| 层 | 说明 |
|----|------|
| **是什么** | 在你电脑上跑开源模型的本地服务（本机 `11434` 端口） |
| **在本课干什么** | 提供脑子，这样不必先买 OpenAI Key |
| **怎么区分** | Ollama 是「模型服务员」；`llama3.1:8b` 是服务员手里的某一道菜（某个模型） |

### `async` / `await`（异步）

| 层 | 说明 |
|----|------|
| **是什么** | Python 里「去等网络/模型回信时，先别把整个程序卡死」的写法 |
| **在本课干什么** | 问模型要几秒；用 `await agent.run(...)` 等待结果 |
| **怎么区分** | 你暂时不用精通异步原理；记住：**现役 AutoGen 示例几乎都是 async 函数** |

### TaskResult

| 层 | 说明 |
|----|------|
| **是什么** | `run` 跑完后的结果盒子，里面有一组 `messages`（对话消息） |
| **在本课干什么** | 我们打印它，看到 user 问了什么、assistant 回了什么 |
| **怎么区分** | 不是「只有最后一句字符串」；是整段对话记录 |

## 3. 对照脚本逐行（打开 `step02_assistant_hello.py`）

| 代码在干什么 | 人话 |
|--------------|------|
| `OllamaChatCompletionClient(model=...)` | 接通本机 Ollama，指定用哪个模型 |
| `AssistantAgent("assistant", model_client=..., system_message=...)` | 创建助手：名字叫 assistant；用上面的模型；系统提示「尽量短」 |
| `await agent.run(task="...")` | 把任务交给助手，**等它跑完**；返回 `TaskResult` |
| `print(result)` / 打印最后一条 | 看盒子里有什么；重点看助手回的那句中文 |
| `await model_client.close()` | 用完关掉连接（官方 Quickstart 也这样写） |

**入参 / 出参 / 何时用（官方依据）**：见 [`lesson_api_cheatsheet.md`](./lesson_api_cheatsheet.md)。

**和上游旧名词的关系（一句就够）**：  
以前教程里的 `ConversableAgent` ≈ 今天这个 `AssistantAgent`。名字变了，角色还是「会对话的助手」。

## 4. 动手（只做这一件事）

先确认 Ollama 在跑，再：

```bash
cd week06/day36-37-autogen-core
```

- 一段 `TaskResult`（里面有 user 消息 + assistant 消息）  
- 最后打印一句中文自我介绍
