# Day59–60 Lesson 3 — 投研 Multi-Agent 系统设计口述（KP3）

> 挂钩：Multi-Agent 工作流；本仓 Day52–56

## 本课唯一新点

把四步骨架**套进投研**，突出「协作形态」，别只说「用了 CrewAI」。

| 步 | 投研版要点 |
|----|------------|
| 澄清 | 输入是否仅公司名？要不要荐股？失败能否降级 fixture？中间稿要不要可审计？ |
| 架构 | 搜集 → 分析 → 撰写；`sequential` + `context`；≥5 工具按人挂载 |
| 瓶颈/监控 | LLM 慢/胡说；工具抖动；中间产出落盘；重试+降级 |
| 权衡 | sequential（可审计）vs 三人并行（快但交接乱）；fixture vs 强制真 Key |

不荐股是产品边界，要在澄清或权衡里主动说清。
