# Day57–58 Lesson 3 — 投研项目协作稿（KP3）

> 挂钩上游简历亮点：Multi-Agent 协作、复杂工作流自动化、为分析师提升 XX% 工作效率

## 本课唯一新点

投研条要写清「协作形态」，不能只写「用了 CrewAI」。

| 上游亮点词 | 本仓证据（Day52–56） | 简历怎么说 |
|------------|----------------------|------------|
| Multi-Agent | 搜集 / 财报分析 / 撰写三人 | 「三人分工：…」 |
| 复杂工作流 | `Process.sequential` + `context`；`intermediate/` | 「顺序流水线 + 中间产出可审计」 |
| ≥5 工具 | 搜索/概览/SEC/指标/写文件 | 「集成 ≥5 工具（…）」 |
| 稳定性 | tenacity 重试 + fixture 降级 | 「工具层重试与降级」 |
| 提升 XX% | **本仓未测人效** | 占位「预计提升分析师 XX% 出稿效率」或不写死 |

已有一条综合 bullet 可拆成 2～3 条更易扫读（协作一条、工具/稳定性一条）。
