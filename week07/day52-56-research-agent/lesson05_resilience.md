# Day52–56 Lesson 5 — 重试 / 降级（KP5）

> 挂钩上游：**稳定性**；异常处理与重试，任务成功率 > 95%  
> 复用：Day20 `tenacity` + 降级缓存

## 本课唯一新点

| | 重试（retry） | 降级（fallback） |
|--|---------------|------------------|
| 解决什么 | **偶发**失败（抖一下再试） | **实在不行**也要有答复 |
| 典型手段 | `tenacity`：多试几次、间隔等待 | 返回 fixture / 缓存 / 明确失败文案 |
| 本课口径 | 工具调用尽量扛过抖动 | 耗尽后不抛崩整条 Crew |

成功率 >95%（本课理解）：在可控抖动下，带重试+降级后，**工具仍返回可用文本**的比例；不是「模型永不胡说」。
