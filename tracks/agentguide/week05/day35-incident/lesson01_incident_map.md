## 一句话

## 本周工具 ↔ 回答什么问题

| 信号 | 本周 Day | 典型问题 | 你看到什么算「有用」 |
|------|----------|----------|----------------------|
| **Trace（链路）** | 29 LangSmith | 慢在哪一步？哪次工具/模型调用炸了？ | 树形 Run：某节点耗时长或 error |

| **检索日志（加码 A）** | 35 ES+Kibana | 海量 JSON 里按 `status=500` 搜？ | Kibana Discover 过滤命中 |

## 易混对照（抽问会考）

| | Metrics | Logs | Trace |
|--|---------|------|-------|
| 粒度 | 聚合（很多请求的统计） | 单次事件（一行一条） | 单次请求里的**步骤树** |
| 擅长 | 「坏了多少 / 多快」 | 「这一枪具体发生了什么」 | 「链路里哪一环拖后腿」 |
| 不够时 | 不知道是哪次请求 | 不知道整体趋势 | 没接 Agent/多跳时树很浅 |

**口诀**：Metrics 看面 → Logs 看点 → Trace 看路径；Docker 先确认「还活着」。

## ELK 加码 A 放在哪

```text
故障 API ──JSON 行──► stdout / 文件
                         │
              （Filebeat 可选，或先手工 bulk）
                         ▼
                   Elasticsearch  ← 存 + 按字段索引
                         │
                      Kibana     ← 人搜 / 过滤
```

- Day34 交付的是 **形状**（JSON）  
- 加码 A 交付的是 **检索**（ES 存、Kibana 查）  
- **不**装 Logstash 也能闭环（A 档）
