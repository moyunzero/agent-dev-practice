## 本课唯一新点

三人各管一段，**交接物**写进下一任的 context——不是三个人抢同一句话筒。

| 角色（上游名） | 职责 | 交给下一位什么 |
|----------------|------|----------------|
| 信息搜集 Agent | 搜公开信息 / 调 API | 搜集笔记（链接+摘要） |
| 财报分析 Agent | 解析财报、算指标 | 指标/要点稿 |
| 报告撰写 Agent | 读前两份，写成报告 | 最终报告文件 |

对照 Day41：旅行规划师 → 本地向导 → 预订专员，同样是 **sequential + context 接力**。
