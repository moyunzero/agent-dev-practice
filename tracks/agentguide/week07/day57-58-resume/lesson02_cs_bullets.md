# Day57–58 Lesson 2 — 客服项目量化（KP2）

> 挂钩上游简历亮点：高并发、低延迟、生产级监控、节省 XX 人力成本

## 本课唯一新点

写客服条时，**每个亮点词都要落到本仓证据**，不要只抄形容词。

| 上游亮点词 | 本仓可辩护证据（Day43–51） | 简历怎么说 |
|------------|---------------------------|------------|
| 高并发 | Locust 本机约 **281 QPS**（50u/30s，库路径） | 「本机压测 QPS≈281」 |
| 低延迟 | 同次压测 **P99≈250ms**（门槛 <500ms） | 「P99≈250ms，低于 500ms 门槛」 |
| 生产级监控 | Prometheus `/metrics` + Grafana；`request_id` 日志 | 「Compose 接入 Prom/Grafana；请求级 request_id」 |
| 部署 | Docker Compose 整栈 API+PG+Prom+Grafana | 「Compose 一键部署整栈」 |
| 节省 XX 人力 | **本仓未测业务人力** | 写成占位「预计节省 XX% 重复答疑」或先不写死数字 |

核心路径一句话：`POST /ask` **先查 Postgres 订单，未命中再 FAQ 回退**。
